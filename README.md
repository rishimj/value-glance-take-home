# Financial Data Filtering & Visualization App

This project is a financial data visualization and filtering app built with **React**, **Tailwind CSS**, and **D3.js**. It allows users to filter, sort, and visualize financial data (such as revenue, net income, and other metrics) over time.

## Features

- **Data Filtering:** Filter data by date range, revenue range, and net income range.
- **Sorting:** Sort the data by date, revenue, or net income in ascending or descending order.
- **Data Visualization:** Interactive charts powered by **D3.js** for dynamic metric visualization.
- **Responsive Design:** Works seamlessly on desktop and mobile devices.

## Running the Project Locally

### Prerequisites

- [Node.js](https://nodejs.org/) (version 16 or higher recommended)
- [npm](https://www.npmjs.com/) (comes with Node.js)

### Instructions

1. **Clone the Repository**  
   ```bash
   git clone https://github.com/rishimj/value-glance-take-home.git
   cd value-glance-take-home
   cd financial-data-app
2. **Install Dependencies

    ```bash
    npm install
3. **Start the Development Server

    ```bash
    npm run dev
This will start the app in development mode. Open http://localhost:3000 in your browser (or the URL shown in the terminal).
